# Painkiller: Overdose VR
_Painkiller: Overdose VR_ is an enhanced version of the original _Painkiller VR_ mod that allows you to play _Painkiller: Overdose_ in VR.

# Requirements
This modification is intended exclusively for _Painkiller: Overdose_ and is not compatible with other modifications.

# Information:
1) The first time you launch the mod, it may take some time to prepare certain game files for proper VR operation. Launching can take anywhere from 30 seconds to 5 minutes. Subsequent launches will be very fast.
2) When launching the modification, the game will delete the LScripts and Textures folders from the Data folder, if they exist. This is required for the modification to function correctly.
3) The modification does not replace any files in the game; when running Bin/Overdose.exe, the game will run unchanged.
4) To remove the modification, delete the executable file _Painkiller - Overdose VR v.1.1.exe_.

# Installation:
1) Copy the _Painkiller - Overdose VR v.1.1.exe_ executable file to the game's root folder (the key Bin and Data folders should be there).
2) Launch _Painkiller - Overdose VR v.1.1.exe_ with the VR headset connected.

# Recommendations:
1) This mod has only been tested on Oculus Quest 2, Oculus Quest 3, but it is expected to work on other devices as well.
2) To launch the game, you must connect to your computer via Virtual Desktop, Steam Link or Meta Horizon Link.
